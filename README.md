# misha-coder Bot

Telegram bot для автоматизации задач в проекте.

## Команды

### Выполнение shell команд
```
cmd: git status
cmd: ls -la
cmd: python script.py
```

### Создание файлов
```
file: path/to/file.txt | Content here
file: src/index.js | console.log('Hello');
```

### Git операции
```
git: status
git: add .
git: commit -m "message"
git: push origin branch-name
```

### Статус
```
status
```

## Использование

1. Запустить бота:
```bash
python3 bot.py
```

2. Отправить сообщение в @Myorbitubot с командой

3. Бот выполнит задание и отправит результат
